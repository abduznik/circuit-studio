Token stays in memory for this tab.
Verify the token before choosing a model.

Why a proxy? Token verification works straight from the browser, but OpenCode's generation endpoints send no CORS headers and answer preflight with 404, so no static page can call them directly. This site can supply a default proxy, and you can override it here. The proxy forwards your token, so it sees it — leave this empty to use a site-provided one, or run your own (proxy/opencode-cors-worker.js). Requests still go browser → proxy → OpenCode; nothing passes through a Circuit Studio app server.

OpenCode Inference: Verify calls GET /inference/v1/models with your token. Generation sends the token and prompt to OpenCode's family-specific inference endpoint, through a CORS proxy when one is used; it does not go through Circuit Studio. Free OpenCode models are reserved for the OpenCode app, so use a paid model with Console credits. If remembered, the token is stored unencrypted in this browser's local storage. OpenCode's token and endpoint docs: Inference API.
